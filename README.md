# مولّد رمز QR

صفحة واحدة لإنشاء رمز QR دائم لا ينتهي: اكتبي الرابط، غيّري لون الرمز والخلفية، واحفظيه كصورة PNG.

- يعمل بالكامل داخل المتصفح، بدون خادم ولا تتبّع.
- متوافق مع الجوال، مع زر مشاركة مباشرة.
- أحجام للحفظ: 512 / 1024 / 2048 بكسل.

الرابط المباشر: https://sfalmohammadi-cmyk.github.io/Qr-code/
